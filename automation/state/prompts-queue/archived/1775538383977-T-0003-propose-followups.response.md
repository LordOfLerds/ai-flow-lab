# Follow-up Tasks for T-0003

## Candidate Tasks

### 1. Tileset & Visual Assets (T-0003-A)
**Priority: HIGH**
**Depends on: T-0003 (implementation)**
**Effort: Medium**

Create visual tileset sprite sheet:
- 16×16 pixel tiles for all 6 types (grass, stone, ice, breakable, moving, one-way)
- Animated ice tile (shimmer/sparkle effect)
- Animated breakable tile (crack progression frames)
- Animated moving platform (wheels or mechanical detail)
- Color consistency across tiles
- High contrast one-way platform with directional indicator

Single PNG spritesheet with transparent background. Provides actual visual feedback instead of colored rectangles.

---

### 2. Level Design & Pre-made Levels (T-0003-B)
**Priority: HIGH**
**Depends on: T-0003 (implementation)**
**Effort: Medium**

Design 3-5 pre-made tutorial and starter levels:
- Tutorial: simple gaps, introduces jumping
- Level 1: introduces ice tiles and friction changes
- Level 2: introduces breakable platforms and moving platforms
- Level 3: combines all mechanics with moderate challenge
- Optional Challenge: difficult level with complex navigation

Each level teaches a mechanic progressively. Include level design documentation (ASCII grid + notes). Ensure all levels are validated before inclusion.

---

### 3. Particle Effects & Polish (T-0003-C)
**Priority: MEDIUM**
**Depends on: T-0002 (player), T-0003 (implementation)**
**Effort: Medium**

Add visual feedback effects:
- Landing dust particles when player hits platform
- Spark effects when breakable platform breaks
- Shimmer particles on ice tiles during movement
- Screen shake on large jumps or breakable destruction
- Tile crack animation during breakable break sequence
- Jump trail effect showing upward motion

Enhances feel and gives clear visual feedback for actions.

---

### 4. Audio System (T-0003-D)
**Priority: MEDIUM**
**Depends on: T-0002, T-0003 (both mechanics)**
**Effort: Small**

Implement sound effects:
- Jump sound (different pitch for different jump heights)
- Land sound (different for different platform types)
- Breakable platform crack/break sound
- Ice slide sound (friction/sliding audio)
- Level complete success sound
- Background music loop with level progression variations

Uses Web Audio API or HTML5 audio elements. Repeatable and toggleable.

---

### 5. HUD & Game UI (T-0003-E)
**Priority: MEDIUM**
**Depends on: T-0003 (implementation)**
**Effort: Small**

Create in-game UI:
- Current level display (top-left corner)
- Distance traveled / percentage to level complete
- Lives/tries remaining (if implementing)
- Speed/velocity display (debug mode)
- Level start fadeout and level complete fadeout
- Pause menu (pause/resume)
- Settings menu (audio toggle, difficulty selection)

Simple canvas-based UI overlaid on main game view.

---

### 6. Difficulty Tuning & Balancing (T-0003-F)
**Priority: MEDIUM**
**Depends on: T-0003-B (levels), T-0002+T-0003 (mechanics)**
**Effort: Small**

Fine-tune game balance:
- Verify jump distance matches platform gaps
- Test ice friction doesn't make traversal impossible
- Validate moving platform speeds aren't too fast/slow
- Test procedural generation produces consistently playable levels
- Tweak difficulty curve (should be smooth, not spike)
- Get feedback on jump feel and responsiveness

Playtesting and iteration on constants.

---

### 7. Advanced Camera Features (T-0003-G)
**Priority: LOW**
**Depends on: T-0003 (implementation)**
**Effort: Small**

Enhance camera system:
- Vertical camera panning when player jumps high
- Screen shake on landing impacts
- Cinematic letterboxing on level completion
- Boss/special event camera behaviors
- Parallax scrolling background (optional)
- Zoom in/out based on player velocity

Adds cinematic polish without affecting core mechanics.

---

### 8. Level Streaming & Performance (T-0003-H)
**Priority: LOW**
**Depends on: T-0003 (implementation)**
**Effort: Medium**

Optimize for larger levels:
- Implement tile chunk streaming (load/unload by camera position)
- Object pooling for particles and effects
- Canvas rendering optimization (batch rendering)
- WebWorker for level generation (non-blocking procedural gen)
- Asset caching and preloading

Only needed if levels become very large or many elements added.
