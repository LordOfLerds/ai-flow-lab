# T-0006 Proposed Follow-up Tasks

## Overview
After T-0006 implementation, these follow-up tasks extend progression mechanics, balance gameplay, and address sequence-breaking risks.

## Follow-up tasks

### T-0006-A: Skill balance and level design audit (Priority: Critical)
- **Goal**: Verify Double Jump + Dash don't enable unintended sequence breaking; redesign levels if needed
- **Context**: T-0006 skills unlock powerful movement abilities; existing levels designed without them
- **Work**: Test all T-0004/T-0005 levels with both skills unlocked; identify softlock zones or unreachable areas; redesign level geometry to accommodate skill usage
- **Owner**: codex (level design)
- **Depends on**: T-0006 (implementation complete), T-0004 (levels)

### T-0006-B: Sprite asset creation for skins (Priority: High)
- **Goal**: Create distinct visual sprites for 5 skins (Ninja, Robot, Wizard, Golden)
- **Context**: Current implementation uses color tinting; full sprite sheets provide better visual polish
- **Work**: Design and draw 5 skin sprite sheets (idle, walk, jump animations); integrate into game; add sprite-swapping logic
- **Owner**: codex (art)
- **Depends on**: T-0006 (implementation complete)

### T-0006-C: Prestige system and New Game+ (Priority: Medium)
- **Goal**: Add post-level-6 progression; unlock cosmetic skins via prestige points
- **Context**: T-0006 caps at level 6; no endgame progression
- **Work**: Design prestige mechanic (reset level, keep XP multiplier); award cosmetic skins on prestige milestones; track prestige count
- **Owner**: codex (game design)
- **Depends on**: T-0006 (implementation complete)

### T-0006-D: Skill tree visualization and management UI (Priority: Medium)
- **Goal**: Improve character select menu with interactive skill tree
- **Context**: Current menu shows list of skills; no visual tree or descriptions
- **Work**: Create visual tree layout showing skill unlock levels and dependencies; add descriptions, stat bonuses; implement click-to-enable/disable UI
- **Owner**: codex (UI/UX)
- **Depends on**: T-0006 (implementation complete)

### T-0006-E: Cross-platform progression (Priority: Low)
- **Goal**: Sync progression across devices (e.g., web and mobile)
- **Context**: Current localStorage is single-device only; no cloud sync
- **Work**: Implement optional cloud save (Firebase or custom backend); encrypt progress data; handle conflicts on multi-device play
- **Owner**: codex (backend)
- **Depends on**: T-0006 (implementation complete)
