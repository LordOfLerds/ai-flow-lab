# T-0005 Proposed Follow-up Tasks

## Overview
After T-0005 implementation, these follow-up tasks improve collectible and power-up mechanics and integrate with other systems.

## Follow-up tasks

### T-0005-A: Performance profiling for magnet system (Priority: High)
- **Goal**: Measure magnet pull performance with max 50 coins; optimize if needed
- **Context**: Magnet updates 50 coins/frame at 60 FPS; 3000 distance calculations/sec potential bottleneck
- **Work**: Create test level with 50 coins and magnet active; measure frame rate; implement spatial grid or culling if FPS drops below 50
- **Owner**: codex (testing)
- **Depends on**: T-0005 (implementation complete)

### T-0005-B: Particle system for gem collection (Priority: Medium)
- **Goal**: Add 3-5 sparkling particles on gem pickup
- **Context**: Gem animation currently scale+fade only; particles deferred from T-0005
- **Work**: Implement particle entity type; emit on gem pickup; fade particles over 0.5s
- **Owner**: codex (enhancement)
- **Depends on**: T-0005 (implementation complete), T-0007 (HUD polish may include particle system)

### T-0005-C: Sound effects for collectibles (Priority: Medium)
- **Goal**: Add audio cues for coin/gem pickup and power-up activation
- **Context**: Audio effects deferred from T-0005; no sound system implemented yet
- **Work**: Design short SFX for coin pickup (high-pitch ding), gem pickup (chime), power-up activation (whoosh)
- **Owner**: codex (audio design)
- **Depends on**: T-0005 (implementation complete), audio system available

### T-0005-D: Power-up combination and synergy (Priority: Low)
- **Goal**: Add special interactions between stacked power-ups
- **Context**: Current implementation treats power-ups as independent; no synergies
- **Work**: Design power-up interactions (e.g., shield + magnet = extended magnet range); implement special combination bonuses
- **Owner**: codex (game design)
- **Depends on**: T-0005 (implementation complete), T-0006 (XP system context)

### T-0005-E: Collectible difficulty scaling (Priority: Low)
- **Goal**: Adjust coin/gem distribution and power-up rarity by level difficulty
- **Context**: All levels use same XP values; no difficulty curve implemented
- **Work**: Add level metadata (difficulty:easy/medium/hard); scale collectible frequency and power-up duration accordingly
- **Owner**: codex (game balancing)
- **Depends on**: T-0005 (implementation complete), level metadata system
