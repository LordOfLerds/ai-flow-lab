# T-0026 Follow-up Proposals

Based on the implementation of the pause button, here are suggested follow-up tasks:

### F-1: Add keyboard shortcut (P key) for pause toggle
**Priority:** medium
**Scope:** Add P key as alternative pause trigger alongside Escape. Update input-handler.js to listen for keydown P event and call togglePause().
**Rationale:** Users expect keyboard shortcuts for common game actions.

### F-2: Add settings menu accessible from pause screen
**Priority:** low  
**Scope:** When paused, show a settings gear icon that opens a simple settings panel (sound on/off, difficulty). Requires new settings-menu.js and CSS.
**Rationale:** The pause screen is the natural location for game settings access.
