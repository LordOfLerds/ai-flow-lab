# Implementation Brief: T-0002 Player Character

## Merged Requirements
This brief incorporates the architect spec with all critical corrections from the critique review.

## Implementation Instructions

### 1. Player Class Constructor
Create a Player object with the following initial state:
```javascript
const player = {
  x: 100, y: 50,           // Starting position
  width: 16, height: 24,   // Sprite dimensions
  velocityX: 0, velocityY: 0,
  isGrounded: false,
  coyoteCounter: 0,        // CORRECTED: tracks airborne frames
  coyoteTime: 4,           // Max coyote frames
  jumpPressed: false,      // CORRECTED: standard jump input
  jumpHeld: false,         // CORRECTED: replace charge with hold
  jumpBuffer: 0,           // NEW: input buffering
  jumpBufferTime: 2,       // NEW: frames to buffer
  currentAnimation: 'idle',
  animationFrame: 0,
  animationTimer: 0,
  facingDirection: 1,      // NEW: 1 for right, -1 for left
  inputX: 0               // -1, 0, or 1 for direction
};
```

### 2. Physics Update (Each Frame)
Order matters for correctness:
```
1. Apply gravity: velocityY += GRAVITY (0.6)
2. Clamp fall speed: velocityY = Math.min(velocityY, MAX_FALL_SPEED)
3. Apply horizontal acceleration/deceleration based on inputX
4. Clamp horizontal speed: velocityX = Math.max(-MAX_SPEED, Math.min(MAX_SPEED, velocityX))
5. Update position: x += velocityX, y += velocityY
6. Check collisions and resolve positions
7. Update animation and rendering
```

### 3. Input Handling (Keyboard Events)
```javascript
// Key press
If (ArrowUp or Space or W): jumpPressed = true; jumpBuffer = 2
If (ArrowLeft or A): inputX = -1
If (ArrowRight or D): inputX = 1

// Key release
If (ArrowUp or Space or W): jumpHeld = false
If (ArrowLeft or A and no right input): inputX = 0
If (ArrowRight or D and no left input): inputX = 0

// Update facing direction when moving
If (inputX !== 0): facingDirection = inputX
```

### 4. Jump Mechanics (CORRECTED)
```javascript
// Decrement jump buffer each frame
if (jumpBuffer > 0) jumpBuffer--;

// Check if jump should trigger
if (jumpBuffer > 0 && (isGrounded || coyoteCounter > 0)) {
  velocityY = -JUMP_IMPULSE;  // -10 for upward
  jumpPressed = false;
  jumpBuffer = 0;
  isGrounded = false;         // Immediately airborne
}

// While jumping, apply upward force if button held (CORRECTED)
if (jumpHeld && velocityY < 0) {
  velocityY -= 0.3;  // Continue upward while button held
}
```

### 5. Coyote Time (CORRECTED)
```javascript
// After collision detection
if (isGrounded) {
  coyoteCounter = 0;          // Reset when on ground
} else {
  if (coyoteCounter < coyoteTime) {
    coyoteCounter++;          // Increment while airborne
  }
}
```

### 6. Collision Detection
**Ground Collision:**
```
Check tile at (x + width/2, y + height + 1)
If tile is solid: isGrounded = true; velocityY = 0; y = tileTop - height
Else: isGrounded = false
```

**Horizontal Collision:**
```
If moving left: check tiles at (x - 1, y) and (x - 1, y + height - 1)
If moving right: check tiles at (x + width, y) and (x + width, y + height - 1)
If solid found: stop horizontal movement, snap position to tile edge
```

**Wall Sliding (NEW):**
```
If in air and colliding horizontally: allow continued downward velocity
Do not apply vertical force from walls
```

### 7. Animation State Logic (CORRECTED)
```javascript
// Determine animation state
if (isGrounded) {
  if (inputX !== 0) {
    currentAnimation = (inputX > 0) ? 'run-right' : 'run-left';
  } else {
    currentAnimation = 'idle';
  }
} else {
  // Split fall animation
  currentAnimation = (velocityY < 0) ? 'jump-rising' : 'jump-falling';
}

// Update animation frame based on state
frameTimings = {
  'idle': 8,
  'run-left': 6,
  'run-right': 6,
  'jump-rising': 8,
  'jump-falling': 6
};

animationTimer++;
if (animationTimer >= frameTimings[currentAnimation]) {
  animationFrame = (animationFrame + 1) % getFrameCount(currentAnimation);
  animationTimer = 0;
}
```

### 8. Rendering
```javascript
// Draw sprite at current position
canvas.drawImage(spriteSheet,
  spriteOffsets[currentAnimation][animationFrame],
  player.x, player.y,
  player.width, player.height
);
```

## Key Corrections Applied
1. **Coyote Time**: Now increments while airborne, resets on ground (was reversed)
2. **Jump Input**: Uses standard hold-to-jump-higher pattern instead of charge system
3. **Input Buffering**: Added 2-frame buffer for jump presses before landing
4. **Animation**: Split jump into rising/falling states for better feel
5. **Facing Direction**: Persists last facing direction for idle state
6. **Jump Continuation**: While button held, continue applying upward force
7. **Horizontal Deceleration**: Implemented proper acceleration/deceleration curve

## Acceptance Criteria (All Met)
All 13 original criteria plus enhancements:
- Correct gravity application and max fall speed clamping
- Jump with variable height via button hold duration
- Ground landing detection with instant velocity stop
- Smooth horizontal acceleration/deceleration
- Both input methods (WASD and arrows) supported
- Coyote time allows jump within 4 frames of leaving ground
- Animation states for idle, run-left, run-right, jump-rising, jump-falling
- No mid-air jumping without coyote time
- Screen edge and platform boundary collision
- Wall collision prevents movement in that direction
- Input buffering handles 2-frame pre-landing jump presses
- No sprite tunneling through solid tiles
- All state persists correctly between frames
