# Follow-up Tasks for T-0002

## Candidate Tasks

### 1. Player Sprite Asset Creation (T-0002-A)
**Priority: HIGH**
**Depends on: T-0002 (implementation)**
**Effort: Medium**

Create pixel art sprite sheet with animation frames:
- Idle animation: 2 frames (16x24px each)
- Run-left animation: 4 frames
- Run-right animation: 4 frames (or mirror left)
- Jump-rising: 2 frames
- Jump-falling: 2 frames

Total: 16x24px frames on a single spritesheet PNG with transparent background. Define sprite offsets/UV coordinates for animation system to index correctly.

---

### 2. Ground and Platform Collision System (T-0002-B)
**Priority: HIGH**
**Depends on: T-0001 (tilemap/level foundation)**
**Effort: Medium**

Implement collision detection subsystem:
- Tilemap reading and collision grid generation
- Axis-aligned bounding box collision checks
- Platform type definitions (static, moving, breakable)
- One-way platform support (top-surface-only collisions)
- Collision response (position correction, velocity nulling)

This enables proper physics integration between player and world.

---

### 3. Input System Refinement & Testing (T-0002-C)
**Priority: MEDIUM**
**Depends on: T-0002 (implementation)**
**Effort: Small**

Create comprehensive input test suite:
- Simultaneous key presses (e.g., left + jump)
- Key release timing edge cases
- Repeat key presses and buffering validation
- Cross-platform keyboard layout support (if needed)
- Define consistent input priority (which direction wins if both pressed)

Ensures robust feeling controls across varied player input patterns.

---

### 4. Player State Machine & Polish (T-0002-D)
**Priority: MEDIUM**
**Depends on: T-0002-A (sprites), T-0002 (implementation)**
**Effort: Medium**

Enhance player with advanced mechanics:
- Wall slide/climb mechanics when touching walls mid-air
- Dash ability (short burst movement with invincibility frames)
- Double-jump variant mode
- Hit-stun and knockback for enemy collisions
- Character state machine for managing overlapping animation states

Adds depth to platformer feel and prepares for enemy interactions.

---

### 5. Camera Follow & Viewport Management (T-0002-E)
**Priority: MEDIUM**
**Depends on: T-0003 (level system), T-0002 (implementation)**
**Effort: Small**

Implement camera system:
- Follow player with smooth lerp interpolation
- Boundary clamping to level bounds
- Screen-shake effects for impactful actions
- Viewport culling for rendering performance

Ensures player stays centered and visible during gameplay.

---

1. **T-0002-B** (Collision System) - Blocking for T-0002 testing; pairs with T-0001

3. **T-0002-C** (Input Testing) - Validates core mechanics; relatively quick
