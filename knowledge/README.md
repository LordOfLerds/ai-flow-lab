# Knowledge Base

KI-Gedaechtnis fuer das AI Flow Lab Projekt. Claude Code liest und schreibt hier ueber den Obsidian MCP Server.

## Ordner

- **decisions/** — Architektur-Entscheidungen und Begruendungen
- **learnings/** — Patterns, Pitfalls, was funktioniert hat
- **context/** — Domain-Wissen, Projekt-Kontext

## Regeln

- Pipeline-Artefakte (Specs, Reviews, Briefs) gehoeren nach `ai/`, nicht hierher
- Truth-Docs (DOMAIN_MODEL, ARCHITECTURE, INVARIANTS) gehoeren nach `docs/`
- Hier kommt nur Wissen rein das nicht in Code oder Git-History steckt
