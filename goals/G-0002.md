# G-0002: Add real gameplay to Pixel Runner: physics, rendering, collision, camera

The game currently has a Start button and basic structure (canvas, HUD, level generation, player creation, skins, skills) but the demo version only shows "Game Started!" text. This goal adds real gameplay: tile rendering with camera scrolling, player physics (gravity, jumping, dashing), collision detection with tiles and enemies, coin/gem/powerup collection, enemy AI (walkers and flyers), death/respawn, level completion (exit tile), and game-over screen. All code goes in index.html (self-contained, no module imports). Keep the existing HUD, overlay, skins, and skill systems intact.
