# ARCHITECTURE

## Scope
This is a small TypeScript test project used to validate an AI-assisted engineering workflow.

## Structure
- `starter-test/src/tasks.ts`: domain logic
- `starter-test/src/index.ts`: demo entry point
- `starter-test/tests/tasks.test.ts`: tests

## Workflow Truth Policy
Docs are the primary truth.
If tested behavior and docs disagree, the conflict must be written to:
- `ai/current-state/drift-register.md`
