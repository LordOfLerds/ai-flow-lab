# AI Flow Lab

A sophisticated AI-assisted development workflow system that orchestrates multiple AI agents (ChatGPT, Claude, Gemini) to automate software development tasks through structured planning, execution, and review cycles.

## Version

**v0.1.0-dev**

## Overview

AI Flow Lab enables autonomous software development by coordinating AI agents across different specialized roles:
- **ChatGPT (Architect)**: System design and task decomposition
- **Claude (Executor)**: Code implementation and git management  
- **Gemini (Reviewer)**: Critical analysis and quality assurance
- **Human Owner**: Goal setting and decision oversight

The system features automated task pipelines, decision gates, follow-up generation, and comprehensive project state management through an interactive dashboard.
